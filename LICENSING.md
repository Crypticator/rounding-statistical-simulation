# License scope

The repository uses separate licenses for software and documents. This is a division by material, not an option to choose either license for every file.

| Material | Applicable license |
|---|---|
| Project-authored executable code, including Python programs, shell commands supplied as software, build programs, verification programs and sampling programs | MIT, in `LICENSE-CODE.txt` |
| Software dependency specifications and software configuration files | MIT, in `LICENSE-CODE.txt` |
| Thesis and paper text, including PDF, DOCX, Markdown, LaTeX and HTML editions; prose documentation; original figures; project-authored reports | CC BY 4.0, in `LICENSE-DOCUMENTS.txt` |
| Project-authored research-data compilations, recorded results and descriptive metadata, including publication and citation metadata | CC BY 4.0, to the extent copyright or similar rights apply |

These scopes apply to the unpacked `papers/` and `thesis/` directories and to the corresponding project-authored materials in the root PDFs and ZIP distributions. An archive is a container, not a new license category. Code excerpts intended as executable software use MIT; surrounding explanatory prose uses CC BY 4.0.
