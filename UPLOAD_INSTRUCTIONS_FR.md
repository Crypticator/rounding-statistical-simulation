# Ajouter les fichiers au dépôt GitHub

Dépôt : https://github.com/Crypticator/rounding-statistical-simulation

1. Décompresser `ROUNDING_GITHUB_COMPLEMENTS_2026-11-18.zip` sur l'ordinateur.
2. Ouvrir le dossier `rounding-statistical-simulation` extrait.
3. Ajouter son contenu à la racine du dépôt : les fichiers de présentation, les licences, `papers/` et `thesis/`. Ne pas créer un deuxième dossier `rounding-statistical-simulation` à l'intérieur du dépôt.
4. Remplacer le fichier `LICENSE` existant par celui de ce paquet. Le texte MIT existant est conservé dans `LICENSE-CODE.txt`; le nouveau `LICENSE` indique le périmètre des deux licences.
5. Conserver les PDF et ZIP déjà déposés à la racine : le paquet ajoute des répertoires consultables et ne demande aucune suppression.
6. Une fois les fichiers ajoutés, vérifier que les liens du README ouvrent les bons PDF et les suppléments.

Les téléversements peuvent être faits par lots dans GitHub, ou en copiant ces fichiers dans un clone local puis en créant un commit. Il faut inclure les répertoires décompressés pour rendre les sources consultables; déposer seulement ce nouveau ZIP ne les rendrait pas directement navigables.

`CITATION.cff` est validé contre le schéma CFF 1.2.0. Aucun DOI ni numéro de release du dépôt n'a été inventé. Le ZIP contient la thèse v0.6 et les quatre articles anglais v1.1; l'ajout de métadonnées ne crée pas une nouvelle édition scientifique.

Les fichiers `papers/` et `thesis/` reproduisent les distributions identifiées. Les anciens comptes rendus et notes datées conservent leur contenu historique. Les programmes scientifiques n'ont pas été modifiés et ne sont pas relancés pour cette opération de conditionnement.
