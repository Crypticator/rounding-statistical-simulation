# Supplementary data

This directory collects exact results, numerical optimization outputs and the recorded computation environments for the thesis and four papers. These are byte-identical convenience copies of the canonical `data/` directories beside the manuscripts. `MANIFEST.csv` maps every copy to its canonical path and SHA-256 checksum.

The original computation dates and dependency versions remain in the environment records. These datasets were preserved, not regenerated for the 18 November 2026 authorship and packaging revision. Exact rational calculations and floating-point optimization have different evidential status; the manuscripts state the domains and limitations.

To reproduce the calculations, use the scripts and instructions in [the thesis](../thesis/README.md) or the [individual paper supplements](../papers/README.md). They reconstruct the scientific objects; this collected data directory is not an input oracle for those calculations.
