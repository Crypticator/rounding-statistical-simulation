# Package validation

This directory records checks for the complete package and the article authorship revisions. It contains the exact editorial source diffs and the preservation and rendering checks. These are packaging and export checks, not a new scientific audit. The mathematical campaigns were not rerun for this editorial change.

The preceding thesis author revision is carried over byte for byte, including its own validation records. Historical audit evidence remains in `thesis/final_review/` and `thesis/prior_reviews/`, with its original scope. The original computation environments and numerical outputs are retained in the individual manuscript directories.
